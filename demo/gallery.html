.art-display is --art-text-5xl and steps down to --art-text-3xl under 768px; .art-display--page is the --art-text-4xl step, for a page that is not the front page. Both take --art-weight-display, which is the dark-theme optical compensation — a literal 700 here would silently opt out of it.

.art-lede

The lede is the one paragraph a page is allowed to centre: a step up in size, a step back in ink, and a measure narrower than the column it introduces.

.art-dropcap — three lines, and the arithmetic that puts it there

The cap is derived from the metrics of the two faces actually in use, at --art-text-base and --art-leading-body: its top sits on the first line’s cap height and its foot on the third baseline. Count the lines beside it. Swapping either typeface without redoing the sum is what turns this from a rule into a coincidence.

.art-dropcap is a component, not a prose rule — it works outside .art-prose, which is where this specimen sits.

Buttons

.art-btn · .art-btn--primary · .art-btn--secondary · .art-btn--outline · .art-btn--ghost — rest

These four are live: hover them, and tab into them. Every row below paints one of their states so the whole matrix can be read at once.

:hover — the fill and the label trade places; nothing darkens

--primary swaps --art-action and --art-action-ink; --secondary swaps --art-accent-strong and --art-accent-ink; --outline fills with --art-ink and sets its label in --art-surface; --ghost gains --art-surface-raised and keeps its label. The border does not move, so the box never changes size. Hover one of these: the kit’s own rule outranks the paint, so if a painted button changes under the pointer, it is the paint that has gone stale.

:focus-visible — 2px --art-focus at a 2px offset, on every control in the kit

The focus contract is declared once, on element selectors rather than on .art- classes, so it also reaches the bare markup a host page brings and the links inside .art-prose. It is not negotiable per app.

[disabled] — a real attribute, not a class

One rule for all four: 0.5 opacity and not-allowed. The hover rules are guarded with :not(:disabled), so a disabled fill never inverts.

The strip is one tab stop: arrow keys move between the tabs, Home and End jump to the ends, and only the selected tab is reachable with Tab. The active tab’s 2px edge overlaps the strip’s own hairline, so it reads as a break in the rule rather than as a bar sitting under it.

A row header is a label for its row, not a column heading, so it is set in the body ink at weight 600 and is neither uppercased nor letterspaced. .art-table__num right-aligns the two figure columns and turns on tabular figures, so the digits line up down the column whatever their width.

.art-code · .art-pre

The measure lives in one token, --art-measure, and is corrected in one place. That is the argument for tokens in a sentence: not that they save typing, but that they leave nowhere for a second, quietly different opinion to survive.

.article__body {
font-family: var(--art-font-body);   /* 拉丁在前，汉字在后 */
font-size:   var(--art-text-base);
line-height: var(--art-leading-body);
max-width:   var(--art-measure);
}

.art-code inside .art-pre drops its own ground and its own size, so a block never renders as a chip inside a chip.
